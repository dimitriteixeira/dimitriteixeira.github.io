Como o Claude Code gera B-rolls no Google Flow

WhatsApp Telegram X (Twitter) LinkedIn Facebook E-mail
Assista no YouTube 9 min de leitura

O começo do meu vídeo tem cenas de café que eu nunca gravei: o Claude Code leu o roteiro, abriu o Google Flow sozinho, gerou os vídeos e encaixou cada um no tempo certo da fala. Aqui estão os prompts reais para montar esse fluxo. Copie, troque o que for do meu jeito pelo seu e siga na ordem.

Etapa 1. Antes de começar

O B-roll é gerado no Google Flow, com os créditos da sua própria conta. Quem clica, escreve o prompt e baixa o vídeo é o Claude, pelo navegador. Você vai precisar de três coisas:

💡
  • Claude Code instalado (claude.com/claude-code). Se você ainda não tem as skills de edição, comece pelo tutorial do Motion Editor
  • Uma conta do Google com acesso ao Google Flow. A conta Pro dá 1.000 créditos por mês e mais 50 por dia
  • Uma conta de teste, só para isso. Não use a conta com seus e-mails, Drive ou canal (explico na Etapa 9)

Etapa 2. Peça para o Claude analisar o MCP base

O Flow não tem API no plano de assinatura. A ponte é um MCP: um conector que dá "mãos" para a IA usar outro sistema, aqui o navegador. Eu parti de um MCP pronto e pedi uma análise de segurança antes de instalar qualquer coisa.

Prompt
https://github.com/GabrielGargiuloDev/google-flow-mcp

Quero que você analise esse repositório e veja se ele é relativamente seguro e se a gente poderia utilizá-lo para gerar imagens com o Nano Banana ou até mesmo vídeos de forma automatizada com a minha conta do Google. Me diga se você acha que é plausível a gente usar isso. Não faça mais nada além dessa análise.
🔗

O MCP base é o GabrielGargiuloDev/google-flow-mcp (licença MIT), que por sua vez foi adaptado do TMSSS05/google-flow-browser-mcp. Obrigado aos dois.

Etapa 3. Instale e entre com a conta de teste

Com a análise aprovada, peça a instalação. O MCP abre um Chrome separado, e é nele que você faz o login uma única vez. Por baixo, quem controla esse navegador é o Playwright.

Prompt
Pode instalar esse MCP aqui no meu Claude Code. Eu tenho uma conta do Google de teste, que eu posso perder sem problema, e é com ela que eu quero usar. Me oriente passo a passo para fazer o login de forma segura no Chrome que você abrir: eu entro com o login na conta do navegador lá em cima ou direto no Flow? Depois faça um teste gerando uma imagem simples e me diga onde ela foi salva.
🔒

O login fica salvo num perfil próprio desse Chrome. A sua conta pessoal nunca entra nele.

Etapa 4. Ensine o Flow do jeito certo

O MCP base funcionava, mas não do jeito que eu queria. Estes foram os ajustes que fiz, conversando com o próprio Claude. Mande um de cada vez e teste depois de cada um:

Ajuste 1 · modo agente
O Flow abre no modo agente, e é nele que tudo funciona: você descreve o que quer e o agente do Flow entende a intenção. Mantenha sempre o modo agente e só mande o pedido no chat dele. Escreva os pedidos em português.
Ajuste 2 · projeto e arquivos
Sempre que for gerar um conjunto de imagens ou vídeos, crie um projeto novo e renomeie o nome do projeto (canto superior esquerdo) de acordo com esse conjunto. E sempre me retorne onde ficou salva cada imagem e cada vídeo no computador.
Ajuste 3 · download em 1080p
Para baixar o vídeo, clique no vídeo gerado: ele abre numa nova janela. No canto superior direito tem um ícone de download; ao clicar, abre um menu com a opção de 1080p, que é sem custo. Use esse caminho para baixar.
Ajuste 4 · formato e quantidade
Quero escolher o formato e a quantidade do que é gerado: proporção 9:16, 16:9 ou 1:1, e de uma a quatro imagens ou vídeos por pedido. Faça isso nas configurações do agente do Flow antes de mandar o pedido.
Ajuste 5 · frame inicial e final
Sempre que gerar imagens, renomeie cada uma com um nome de referência que possa ser citado no prompt depois. Por exemplo: gere uma imagem de um apartamento vazio (@sala-vazia) e depois a mesma sala, mesmo enquadramento, cheia de móveis (@sala-decorada). Na hora de gerar o vídeo, especifique no prompt que o frame inicial é @sala-vazia e o frame final é @sala-decorada, e descreva o movimento: os móveis aparecendo aos poucos, como um stop motion animado com um som ritmado.
Ajuste 6 · créditos com aprovação
Vídeo gasta créditos. Quando o Flow pedir confirmação, pare e me mostre o custo antes. Só aprove depois que eu disser sim. Nunca marque "Sempre aprovar no projeto".

Etapa 5. Transforme em skill

Com tudo funcionando, peça um resumo do que o MCP já faz e transforme isso numa skill. Assim qualquer conversa do Claude Code sabe usar o Flow.

Prompt
Antes de criar a skill, me explique de forma resumida tudo que o MCP do Google Flow consegue fazer agora. Depois use a skill skill-creator e crie uma skill "google-flow" que ensina a usar esse MCP: gerar imagens com nome de referência, gerar vídeos (inclusive com frame inicial e final), baixar em 1080p, sempre informar onde os arquivos ficaram e sempre pedir a minha aprovação antes de gastar créditos.

Etapa 6. Conecte ao Motion Editor

Esse é o pedido que juntou tudo. Mande no chat da pasta da skill motion-editor:

Prompt
Conecta esse MCP do Google Flow agora com o nosso Motion Editor. E cada vez que tiver uma oportunidade de colocar um B-roll mais elaborado, em vídeo ou em imagem, use o MCP do Google Flow para fazer isso.

Etapa 7. Peça os B-rolls na edição

Daqui pra frente é só falar o que você quer. Este foi o pedido que gerou o começo do vídeo. O Claude leu a fala, escolheu as cenas, gerou cada uma no Flow, baixou e cortou no tempo certo da narração.

Prompt
/motion-editor Edite para mim o vídeo: "D:\Videos\meu-video.mp4". Na parte em que eu falo sobre café e várias descrições do processo, devem ter pequenos trechos exemplificando o que eu estou falando, com vídeos de 3 segundos de B-roll que precisarão ser cortados para se encaixar na fala. Use o MCP do Google Flow para isso. Eu começo falando em tela cheia, rapidamente já faz uma transição para os B-rolls e na parte final eu devo voltar a aparecer em tela cheia.
✏️

Troque o caminho do vídeo e descreva o trecho do seu jeito. Quanto mais claro o que cada cena deve mostrar, melhores os B-rolls.

Etapa 8. Quanto custa

Gerar imagens com o Nano Banana no Flow não gasta créditos. Vídeos gastam: fica entre 15 e 30 créditos por vídeo, dependendo do modelo e da duração (no meu teste, um vídeo de 4 s no Omni Flash custou 12 créditos). Com a conta Pro, você recebe 1.000 créditos por mês e mais 50 por dia.

💸

O plano Pro custa por volta de R$ 96 por mês. Existem formas mais baratas (plano estudantil, assinatura compartilhada, promoções), então vale pesquisar antes.

Etapa 9. Os dois cuidados

O MCP usa a sua conta pelo navegador, como se fosse você. Isso é ótimo, mas traz duas consequências:

⚠️
  • Pode quebrar. Se o Google mudar a interface do Flow, o MCP para de funcionar. Fique de olho durante a edição: sem isso, o Claude pode ficar tentando de novo e gastando tokens
  • A conta pode ser bloqueada. As plataformas têm política contra uso automatizado. É raro, mas pode acontecer. Por isso, use uma conta de teste que você possa perder

Quando quebrar, é só pedir para o Claude consertar. Foi o que aconteceu durante a edição deste vídeo: o Google trocou o nome de um botão e o Claude ajustou o MCP na hora.

Prompt
O MCP do Google Flow parou de funcionar e está dando este erro: [cole o erro aqui]. Acho que a interface do Flow mudou. Abra o Flow no Chrome do MCP, veja como a tela está agora, ajuste o código do MCP para a interface nova e faça um teste. Não gaste créditos no teste sem me perguntar.

Pronto

O Claude lê o roteiro, escolhe o B-roll, gera no Flow e encaixa na edição. Você só aprova.
